Explain how a modern GPU executes a matrix multiplication, starting from the memory hierarchy and working up through the tiling strategy a well-tuned kernel uses. Cover global memory, L2, shared memory or LDS, and the register file, and explain why each level exists and what its bandwidth and latency characteristics are. Then describe how a tiled GEMM maps onto that hierarchy: how tiles are chosen, how double buffering hides latency, and what happens when the tile size is badly matched to the cache. Finish by explaining what changes when the matrix is quantized to 6 or 8 bits per weight instead of 16.
